## 📌 Featured Project

<div align="center">

### [🎯 Candidate Copilot](https://github.com/iamchgopi/candidate-copilot)
**[→ Live Demo](https://candidate-copilot.vercel.app)**

An AI copilot that matches a resume against multiple job descriptions at once and identifies the single highest-leverage skill to learn next — grounded in retrieved evidence, not guesswork.

</div>

| Feature | What it does |
|---|---|
| 🔍 **Explainable RAG Matching** | Every score cites the exact resume evidence behind it |
| 🎯 **Skill ROI Aggregator** | Finds the one skill blocking the most roles across your whole search |
| 🗣️ **AI Mock Interviews** | JD-tailored practice questions with live feedback |
| ☁️ **Fully Cloud-Deployed** | Render + Vercel + Gemini — zero local dependencies |
